# Prompt for Claude Design — the chat one-pager (copy-paste below the line)

*Run this AFTER design pass 2, ideally in the same session (the identity is already loaded). Output goal: a single image the owner pastes into the Telegram group so members instantly get what the bot does and which commands to use.*

---

One more deliverable: a **one-pager announcement graphic** for the Telegram chat itself. The owner will export it as an image and post it in the group, so it must read perfectly on a phone inside a chat bubble at a glance — this is a poster, not a document.

**Format:** one portrait artboard, 1080×1350 (4:5 — survives Telegram's preview crop better than tall formats). Keep the outer 48px safe: chat UIs round corners and overlay timestamps.

**Identity:** full Degen Neon, same tokens and palette laws as the canvas (magenta = brand, cyan = analysis, green/red = P&L only, Space Grotesk display + JetBrains Mono numbers, no emojis). The overseer wordmark anchors it. This image IS most members' first impression of the product — it should look like the board they'll open.

**Content to convey (compress ruthlessly — headlines and imagery over sentences):**

1. **What it is, one line:** overseer watches every contract posted in this chat — nothing gets missed. Called mcap, peak, multiple: tracked from the second it's posted.
2. **The board** (hero visual): a stylized mini-render of the board — Pulse strip ("15 calls today · best 2.4x"), a few token rows with sparklines and multiples, the section names visible (FRESH / RUNNERS / RETRACED / REVIVING / DIED / RANGING / SLEEPERS). Real-looking data, invented tickers fine.
3. **Alerts into this chat:** watch a coin and "NUKE >40% in 15min" / "BUY OPP ≥30% retrace" alerts arrive as replies to the original call. Max 3 coins on watch per member. Render this as a tiny Telegram-style reply bubble mock — imagery, not a paragraph. The bubble may mirror the REAL alert format (those messages do lead with 🚨 / 🟢 in chat); everywhere outside that mock, the no-emoji law holds.
4. **It cleans up after rugs:** coins that rug auto-hide, get a 24h second chance, and come back as REVIVING if they reclaim $30K — the feed stays honest without anyone lifting a finger.
5. **Commands** (mono, compact, exactly these):
   - `/overseer` — open the board
   - `/overseer watch <ca>` — alerts on for a coin (3 slots each)
   - `/overseer unwatch <ca>` — free a slot
   - `/overseer watchlist` — what's being watched, and by whom
   - `/overseer alerts` — current alert thresholds
   - `/overseer set <param> <value>` — tune them (group-wide)
6. **Footer:** the bot handle @overseergroupbot + "board opens in Telegram — full version in your browser, one tap".

**Tone laws:** neutral data framing everywhere — never "buy", never advice language; retrace/range/multiple are facts. No hype punctuation. The energy comes from the visual system, not exclamation marks.

**Imagery direction:** the call-story sparkline (dotted baseline, peak dot, drawdown shade) is the signature mark — use it. Band bars and the multiple-as-hero number are the other two motifs that say "overseer" without words. Compose those three rather than inventing new illustration styles.
