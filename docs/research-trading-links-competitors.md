# PART A — Deep-link URL formats (verified 1 Sep 2026)

## Context that changes the answer: Robinhood Chain status
- Robinhood Chain mainnet went live **1 July 2026**; Arbitrum Orbit (Nitro) Ethereum L2; **chain ID 4663** ("HOOD" on a phone keypad); RPC `https://rpc.mainnet.chain.robinhood.com`; explorer `robinhoodchain.blockscout.com` (chainlist.org/chain/4663, robinhood.com support article).
- Venues confirmed supporting Robinhood Chain: **Axiom** (added 11 July 2026), **GMGN**, **DexScreener** (slug `robinhood`), **Maestro** (docs list it, Uniswap V2/V3/V4 + Virtuals), **OKX web3** (slug `robinhood-chain`), DEXTools, GeckoTerminal.
- NOT (or not verifiably) on Robinhood Chain: Photon (Sol/ETH/Base/Blast/BNB/Tron only), Trojan (Solana-only), Bloom (Sol/BSC/ETH/Base), Banana Gun (ETH/Sol/Base/Blast). **BullX suspended all trading 1 June 2026** (wallet withdrawals only, no restart date) — do not build BullX links.

## Per-venue formats

### DexScreener (no login needed — best default "chart" link)
- `https://dexscreener.com/{chainSlug}/{pairOrTokenAddress}` — chain slug for v1 is `robinhood` (live: `dexscreener.com/robinhood`). Passing a token address redirects to its top pair.
- Free API verified live: `https://api.dexscreener.com/latest/dex/tokens/{tokenAddress}` returned 30 Robinhood-chain pairs for PONS (`0x39dBED3a2bd333467115dE45665cC57F813C4571`) with chainId `"robinhood"`, pairAddress, price, FDV — this API is also a candidate market-data source for Groupie itself.
- Referral program: **none found** (no ref URL parameter; they sell ads/Enhanced Token Info instead).

### Axiom (axiom.trade) — format verified with live Robinhood-chain examples
- Token page: `https://axiom.trade/t/{tokenAddress}/@{refHandle}?chain=robinhood`
  e.g. `axiom.trade/t/0x39dbed3a2bd333467115de45665cc57f813c4571/@sariosol?chain=robinhood` (PONS). The `/@handle` segment **embeds a referral in the token deep link** — ideal for Groupie.
- Referral signup link: `https://axiom.trade/@{handle}`. Commissions: 3 tiers — 30% (direct) / 3% / 2% of Axiom's net fee; referred users get a 10% fee discount (docs.axiom.trade referral-program page).
- Solana variant: same `/t/{mint}` path without `?chain=` (UNCERTAIN whether `?chain=sol` is required; older guides also show `axiom.trade/meme/{pairAddress}` for Solana — treat `/t/` as canonical).

### GMGN (gmgn.ai) — formats from official docs (docs.gmgn.ai/index/referral-link)
- Token page with referral **embedded in path**: `https://gmgn.ai/{chain}/token/{ReferralCode}_{TokenContract}`
  - Robinhood chain slug is `robinhood` — live indexed examples: `gmgn.ai/robinhood/token/0x39dbed...` (PONS), and ref-embedded `gmgn.ai/robinhood/address/C7KoyPop_0x54d2...`.
  - Solana: `gmgn.ai/sol/token/{ref}_{mint}`.
- Plain referral: `https://gmgn.ai/?ref={code}` or `gmgn.ai/r/{code}`; chain-scoped `gmgn.ai/?chain={chain}&ref={code}`.
- Telegram bot deep link incl. token: `https://t.me/gmgnaibot?start=i_{ref}_{chain}_{tokenContract}` (plus chain bots GMGN_sol_bot / GMGN_bsc_bot / GMGN_swap_bot / GMGN_tron_bot with `?start=i_{ref}`).
- Rebates: volume-tiered, commonly cited up to ~30% off the 1% fee (docs don't publish exact %).

### Maestro (Telegram bot) — supports Robinhood Chain
- Sticky referral: `https://t.me/maestropro?start=r-{refCode}` (also @maestro / @MaestroSniperBot). 25% lifetime commission; 1% per-trade fee.
- **Quick-Buy links** (token-specific, pay 25% commission) exist per docs (docs.maestrobots.com/sniper/referral-program.md) but the exact URL template is generated inside the bot via `/referral` → "enter a token contract address". Widely seen wild pattern is `t.me/maestro?start={tokenCA}-{refCode}` — **UNCERTAIN, generate one in the bot to confirm** (5-minute task for the owner).

### Banana Gun (Telegram bot) — documented "Banana Button" integration format
- `https://t.me/BananaGunSniper_bot?start=snp_{refID}_{tokenCA}` (refID generated by the user; earns commission and pre-loads the token). Solana bot is `@BananaGunSolana_bot` — same `snp_` pattern is the wild convention but UNCERTAIN for the Solana bot specifically. Rewards claim at `dashboard.bananagun.io/referral` (10% of referred fees). No Robinhood Chain support found → skip for v1.

### Trojan (Solana only)
- Referral: `https://t.me/solana_trojanbot?start=r-{refName}` (multiple live examples; alternate bot usernames like `menelaus_trojanbot` exist for load-sharing). Token-embedded deep link: UNCERTAIN (not documented publicly). Irrelevant for Robinhood v1; note for a later Solana chain.

### Bloom
- Referral: `https://t.me/BloomSolana_bot?start=ref_{code}` (docs.bloombot.app: 25% of Bloom's 1% fee to referrer, 10% cashback to referee). Chain-specific docs/bots exist for BSC/ETH/Base. Token-embedded (`..._ca_{mint}`-style) deep link: **UNCERTAIN — verify in-bot**. No Robinhood support → skip for v1.

### Photon (tinyastro) — no Robinhood Chain
- Per-chain subdomains, path `/en/lp/{pairAddress}` (pair/LP address, NOT token address):
  - Solana: `https://photon-sol.tinyastro.io/en/lp/{pair}` (live example verified)
  - ETH: `https://photon.tinyastro.io/en/lp/0xe518e8db...` (live), Base: `photon-base.tinyastro.io/en/lp/0x58342...` (live), Blast: `photon-blast...`, BNB: `photon-bnb...`
- Referral: points-based program; personal links look like `photon-sol.tinyastro.io/@handle`; whether a ref param can ride on an `/en/lp/` link is UNCERTAIN.

### BullX — effectively dead for trading
- Format (verified via indexed live URL): `https://neo.bullx.io/terminal?chainId={id}&address={tokenAddress}&r={refCode}` (Solana uses chainId `1399811149`; EVM chains use numeric EVM chain IDs, so Robinhood would presumably be `4663` — moot). Trading suspended 1 June 2026, no restart date, community calling it exit-farming. **Do not integrate.**

### OKX (web) — supports Robinhood Chain
- Token page: `https://web3.okx.com/token/{chainSlug}/{tokenAddress}` — verified live for `ethereum` (USDT) and **`robinhood-chain`** (PONS page rendered with price/mcap). Solana: `web3.okx.com/token/solana/{mint}` (same structure; spot-check once). Robinhood-chain DEX market list: `okx.com/en-us/markets/dex/robinhood-chain`.
- Mobile-app deep link scheme (`okx://...`): UNCERTAIN — the web URL opens/hands off to the app on mobile. Referral param on web3 token pages: none found (OKX referral codes are exchange-signup codes, not token-page params).

# PART B — Competitive scan: call tracking for Telegram crypto groups

## In-group bots (the incumbents Groupie's group already uses)
- **Rick (@RickBurpBot)** — chat-native scanner for TG+Discord (~20k groups, 100k MAU; data via Codex). Per-CA scan cards (mcap at call, ATH, liquidity, first-buyer PnL), **first-caller attribution**, ATH leaderboards (`/ga`, BurpBoard hourly/weekly/monthly, `ago` for past periods), price widgets/watchlist (last 15 tokens), deep-link buttons to venues (Photon, BananaGun, Maestro etc.), chat/YouTube TLDR. Pricing: non-AI commands **free**; AI commands use credits (~500≈$10, 1000≈$20 via Telegram Stars). Gaps: everything lives inside chat scrollback; no time-filtered board, no "died after call" view, **no web dashboard for a group's calls**.
- **Phanes (@phanes_bot)** — free all-in-one price/scanner bot, 18 languages, read-only (never touches funds). Logs **who called a token first**, ranks members by realized ROI, auto-posts multiplier alerts (2x/5x/10x…) and migration alerts across groups, leaderboards, holder data on any chain, charts. Pricing: **entirely free** (marketing claim on phanes.bot). Has a "Phanes DApp" (dapp.phanes.bot) — fetch blocked (403), contents UNCERTAIN, appears token-utility rather than a per-group calls dashboard. Same gap: in-chat only, updates get buried in the same noise they measure.
- **CallAnalyser (@CallAnalyserBot / @CallAnalyser channels, ~50k subs)** — KOL-performance analytics: send a CA → how many tracked KOLs called it + their ROI; send a channel link → that channel's score (e.g. 89/100) and stats; leaderboard channels for SOL/TON etc. Aimed at *public KOL channels*, not your private group's members. Pricing not published (listing in their index is by request). No per-group web dashboard.
- **SpyDefi** — tracks 2,500+ KOL Telegram channels across major L1/L2s: win rate, average X, avg call mcap, first-in-network calls; customizable real-time filtered call feed (filter by KOL stats, chain, mcap, token age, word-scraping); achievement posts for KOLs; buybot for projects. Again channel/KOL-oriented — it does not ingest *your* private group and give members a board.
- **Alpha Gardeners** — NFT-gated Discord/TG alpha community with scanner tools and AG Sniper; a community with tools, not a call-dashboard product for other groups.
- DIY tier: open-source scripts exist (e.g. GitHub `telegram-group-crypto-call-analyzer`) — confirms demand, no product polish.

## Web dashboards that connect to a Telegram group and show its calls outside Telegram
**This category is essentially empty.** Extensive searching found: generic signal-provider dashboards (Dash 2 Trade — its own signals, not your group's), KOL trackers (SpyDefi, CallAnalyser — public channels, not private groups), group-management SaaS (Telership, Modr8 — moderation/payments, no market data), and Robinhood-chain screeners (Nock Terminal, StalkChain, HoodTracker, Stock Terminal — chain-wide, not group-scoped). No product found that does "add a bot to *your* group → get a private, time-filtered web board of *your* group's calls with live market data." UNCERTAIN: small/unlaunched products may exist that aren't indexed, but nothing surfaced across ~10 targeted queries.

## Where Groupie genuinely differs
1. **Group-scoped web surface** — the board of *your* group's calls outside Telegram is an unoccupied niche; every incumbent either stays inside chat (Rick/Phanes) or tracks public KOL channels (SpyDefi/CallAnalyser).
2. **Time-filtered recall** (6/12/24h/3d/w/m) — solves the actual pain ("missed it in the noise"); in-chat bots can only re-post, adding noise.
3. **"Died after call" section** — no incumbent surfaces failures; Rick/Phanes leaderboards are winner-biased (ATH multipliers).
4. **Pre-launch X-account launch monitoring** tied to group commands — nothing comparable found in any incumbent.
5. **Robinhood-Chain-first** — every TG trading/scanner bot is Solana-first; the HOOD trench-tool ecosystem is weeks old and thin.
6. **Referral monetization** — Axiom/GMGN embed referral codes directly in token deep links (30% and volume-tiered commissions respectively), so the dashboard's outbound links can fund the hobby project.

Groupie should NOT try to compete on: in-chat scan cards (Rick/Phanes own that, are free, and coexist — Groupie can even parse their messages), KOL rankings across public channels (SpyDefi), or trading execution (regulatory + custody risk; link out instead).

## Bottom-line recommendation

For v1 on Robinhood Chain, build a 5-link row per called token using only venues verified to support the chain: Axiom `axiom.trade/t/{ca}/@YOURHANDLE?chain=robinhood` (primary — referral handle embeds directly in the token deep link, 30% direct commission), GMGN `gmgn.ai/robinhood/token/YOURCODE_{ca}` (referral also path-embedded), Maestro `t.me/maestropro?start=r-YOURCODE` (only Robinhood-capable Telegram bot; upgrade to per-token quick-buy links after generating one in-bot to confirm the format), DexScreener `dexscreener.com/robinhood/{ca}` (chart, no referral), and OKX `web3.okx.com/token/robinhood-chain/{ca}`. Skip BullX entirely (trading suspended June 2026) and defer Photon/Trojan/Bloom/BananaGun to the multi-chain phase since none support Robinhood Chain. Register referral codes on Axiom, GMGN, and Maestro before launch — they are the monetization path. Competitively, proceed with confidence: in-chat bots (Rick, Phanes — both effectively free) own scan cards and should be treated as complements/data sources, KOL trackers (SpyDefi, CallAnalyser) only cover public channels, and no product was found that gives a private group a time-filtered web board of its own calls with a died-after-call view and X launch monitoring — that combination is Groupie's genuinely open lane, and DexScreener's free token API is a workable v1 market-data source.
